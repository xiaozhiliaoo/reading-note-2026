# 量化投资策略

马丁策略：亏损后加倍下注，在下一次获胜时能够弥补之前的亏损。分批买入，一次卖出。
网格策略：不加注的马丁策略。自动高抛低收。全部卖了。
无限网格策略：上涨行情中确保握有等值的计价货币资产。使用无限网格策略，用户无论卖多少次，还是拥有与上一个仓位等值的资产。只卖本金的部分。
定投策略：不按空间涨跌加仓，按照固定时间加仓。
智能持仓：多元持仓，分散风险。

第十集：股票期权的投资者适当性管理

五有一无：
三级准入：
一级：持有股票，卖出认购期权（备兑开仓）或买入认沽期权（保险策略）
二级：不持有股票买入期权。

第十一集：股票期权的价格

期权：给权利定价。

期权类比于保险。

行权价越高，风险越高。

时间越短，越便宜。和保费一样。

第十二集：股票期权对投资者的用途

1. 为股票或现金买保险。持有股票买入认沽期权进行保险。持有现金买入认购期权。
2. 降低买入成本。卖出认沽期权。
3. 赚取时间价值，增强持股收益。持有股票觉得上不大，卖出股票大于当前股价的认购期权。赚权利金。赚取虚值期权的时间价值。
4. 进行杠杆性看多或看空的方向性交易。
5. 通过组合策略交易，形成不同的风险和收益组合。4种基本头寸组成不同的策略。

第十三集：股票期权的买方风险

买方锁定了损失，但是权利金可能全部损失。血本无归。

理论：风险有限，权利无限。实际投资：风险很大。

第十四集：股票期权的卖方风险

卖方遇到上不封顶的风险。亏损无限无限。

卖出到期日时间，可以安稳收入权利金。类似于保险公司，收取保费。

第十五集：新技能之巴菲特的优雅

买入认沽期权投资者觉得cola股价会降低到35美元。锁定了35美元卖股票权利。
到时候35美元以上，买方不会以35美元卖。巴菲特赚到750w权利金。如果跌到35美元，巴菲特以35美元买cola。只有cola跌破33.5美元才真正亏损。
策略：现金担保卖出认沽期权。判断后市不会大跌，一定程度愿意低价持有股票。

希望下跌买入股票。
高抛低吸。

第十六集：新技能之长期投资必备良器

备兑开仓策略：持有股票（备兑）+ 定期卖出认购期权。反复卖认购期权获得股票的租金。

第十七集：新技能之为股票买保险

保险策略：股票保险。保护性买入认沽策略。持有股票同时买入认沽期权。保留上行收益，也防范下跌风险。股价上涨保险不起作用，保费不会退，下跌才起作用。

衣领策略：持有股票，买入认沽期权+卖出认购期权。给备兑开仓买入下跌保护，也给保险策略降低保费。

第十八集：新技能之以小博大的杠杆效应

杠杆性做多/做空。

买期权就是锁定未来买卖价。

未来股价会上涨，自有资金不足，买入认购期权本质在加杠杆。

权利金金额比股票便宜很多。

前提对后市看涨或看跌。

第十九集：新技能之卖方收租

预期后市不会大涨，也不会大跌，可以用收入策略。

适当者管理的三级权限。

和备兑开仓不同在于不需要持有标的证券。
备兑开仓是特殊一种情况。
只有义务没有权利，要交保证金，风险较大，在三级权限。

温和看空后市，不会上涨：卖出认购期权。
温和看多后市，不会下跌：卖出认沽期权。长期看好标的证券，愿意以低价买入。巴菲特常用技巧。保证金风险，流动性风险等。
