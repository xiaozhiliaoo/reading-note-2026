# DeFi与金融的未来

传统金融体系是少数人的游戏，但得益于以太坊的开源性，开发者可以利用许多现成的资源，打造自己的DeFi平台。

LUNA是一种算法稳定币，采用类似于“跷跷板”的机制与美元锚定

稳定币就是起源于DeFi的极具价值的创新。稳定币可以让全世界的任何人在全球各地使用加密货币，人们在使用过程中无须接受中心化机构审查，具有完全的自主性，还可以享有美元般的稳定购买力。而且就算美元不稳定了，稳定币也是稳定的。

DeFi本质上是一个充满竞争的分布式金融应用市场，这些应用可以提供金融的基础功能，比如交易、存储、贷款和代币化。

股票暗池交易：大机构将大宗交易都转移到暗池中，这是因为在暗池的点对点交易，比传统的交易所交易成本低得多。

价值与有形和无形没有关系。

比特币仍将作为重要的价值储藏手段和对冲长周期通胀的资产。与黄金一样。

DeFi支持者认为，所有金融基础设施都应该替换为智能合约，进而可以为更多的人提供更多价值。

智能合约是运行在区块链上的代码

ERC-20同质化代币 ERC-721非同质化代币。代币是独一无二的，通常用于收藏品和金融资产，比如点对点借贷。

预言机（oracle）是能播报区块链外部信息的数据源。合约和账本之外的世界是隔离的。

稳定币的价格可以和美元或黄金锚定，可以维持价格稳定。三种机制：法币抵押，加密货币抵押，无抵押。

```text
法币抵押型稳定币：USDT，USDC
加密货币抵押稳定币：DAI，sUSD
无抵押稳定币：Basis，Ampleforth（AMPL），Empty Set Dollar（ESD）
```

DAO通常需要某种治理代币（governance token），持有者拥有一定比例的投票权，可以对社区提案进行决策。

同质化代币是以太坊和DeFi的里程碑。

美元就是同质化资产。

同质化代币：权益代币，功能代币，治理代币

NFT可用作拥有某项资产的独有证明。

NFT的用途之一是可用作点对点贷款的所属权，这个贷款具有特定的利率和条款。
另一个用途是彩票，因为只有一张或有限数量的彩票会中奖，其余彩票没有价值，所以彩票是非同质化的。
NFT还有一个强大的用途，是通过收藏品连接金融和非金融领域。例如，代币可以代表艺术品、视频、音乐，甚至是一条推文的所有权。NFT也可以表示游戏或其他场景中的稀缺物品，并在NFT的二级市场实现保值。

调整供给是通过智能合约提高（铸币）或降低（销毁）同质化代币的供给。

流动性挖矿。

激励：抵押激励，直接激励

抵押奖励（staking reward）
抵押惩罚（消减 slashing）

互换（swap）就是将一种代币换成另一种。

在以太坊上，以非托管的方式进行代币互换的平台是去中心化交易所（Decentralized Exchange，简写为
DEX）目前DEX 有两种主要机制确保流动性：订单匹配（ order book matching ）和自动做市商（Automated Market Maker，简写为AMM）

自动做市商的缺点之一是伴有非固定损失（impermanent loss）

稳定币交易对特别受自动做市商欢迎。

价格和流动性的波动都会引发非固定损失，因为合约被设置成卖出升值资产、买入贬值资产。

# Linux高性能网络详解

以太网卡工作在OSI 体系结构的第二层，即数据链路层。每一个以太网卡都有一个被称为MAC 地址的独一无二的48 位串行号.

Linux 操作系统中的TCP/IP 协议栈. 4层。

交换机在2层，路由器在3层。

常见的总线包括I2C（inter-integratedcircuit）、SPI（serial peripheral interface）、USB（universal serial bus）、SATA（serial
advanced technology attachment）、PCI（peripheral component interconnect）Express。本书中涉及的网卡设备都是通过PCI
Express 总线连接到CPU，

一条PCIe 链路可以由多条Lane（通道数）组成，目前PCIe 链路可以支持1、2、4、8、12、16 和32 条Lane。也就是说存在×1、×
2、×4、×8、×12、×16 和×32 宽度的PCIe 链路。

PCIe：为显卡（如NVIDIA RTX、AMD Radeon）、高速SSD（如NVMe）、网卡（如10G/40G以太网）提供高带宽支持。

NVMe：基于PCIe + NVMe协议栈。NAND闪存、Optane SSD。
NVMA：直接通过CPU内存控制器访问。持久化内存（如Optane PMem）

• NVMe是存储协议，解决“如何快速读写SSD”的问题。
• NVMA是内存技术，解决“如何让非易失性内存像DRAM一样工作”的问题。

PCIe：PCI Express

网卡作为需要高速处理数据的设备，一般是通过PCIe 总线和CPU 相连的。

在通过网卡发送数据时，CPU 会先将数据写入主机内存，并通知网卡（通过PCIe 总线和内部总线）来读取。接收时则相反，网卡会先将数据存放进主机内存，再通知CPU
来读取。这种由网卡设备（不经过CPU）直接访问主机内存的操作方式被称为直接存储
器访问（direct memory access，DMA）

4 种网卡：

Linux 略显臃肿的网络协议栈已经无法满足用户对性能的需求。于是人们开始另辟蹊径，开发了多种新型的网络技术方案，比如DPDK、RDMA、XDP等。

网卡：内核协议栈方案的网卡称为以太网卡 VS RDMA 网卡

Linux 内核网络协议栈为基础的应用方案存在的3个缺点：

1. 软件运行时频繁地在内核态与用户态之间切换；
2. 在内核空间与用户空间的缓存之间，存在大量的数据复制行为；
3. 数据包的封装和解析工作由CPU 执行。

消耗大量的CPU 运行时间，增加了发送和接收数据包过程中的时延。

RDMA 通过绕过软件协议栈和避免不必要的数据复制来实现低时延、降低CPU 占用率、减少内存带宽瓶颈和提供高带宽。

over Converged Ethernet）

RDMA 已经是一个比较成熟的架构，主要应用在高性能计算HPC领域和大型数据中心中，典型的应用场景包括分布式神经网络计算（比如TensorFlow+MPI+RDMA）和大数据存储（比如HDFS+RDMA+NVMe）等。

1. 做市交易策略：最主流策略，做市商同时在订单簿两侧提交限价单，为那些想成交的市场参与者提供流动性，自身获取买卖价差做盈利。做市商放买卖单的价差取决于：订单处理成本，存货成本，信息成本，比如让买卖单覆盖成本。

### 美国对高频监管

2010年闪电崩盘后才开始监管。闪电崩盘还没有确定原因。

1. 禁止闪电指令。
2. 禁止无审核通路。（越过中介直接交易所）
3. 巨量交易者识别。
4. 托管（co-location）。自己撮合放在交易所主机旁边。

### 德国对高频监管

出台最早，欧洲的。高频交易监管领先，非常严格。其他国家先参考德国。

1. 高频交易商纳入了监管对象。市场准入制。做市义务。
2. 建立有效的风控系统。
3. 界定了高频交易市场操纵行为。试探性指令 ping orders。误导性交易。引发动量交易，分层和欺诈交易。
4. 指令成交比例，最小报价单位限制。报价单位很难的题，没有参考。

### 中国对高频监管

1. 认识功能和作用。
2. 实现公司和个人进行备案，做市商必须做市业务。
3. 保证公平性。
4. 预防市场操纵。
5. 跨市场联动。

III 动态展望（2025年更新趋势）。

市场质量提高：1. 买卖价差 2. 市场深度 3. 交易成本降低 4. 交易执行时间

Markets in Financial Instruments Directive - MiFID

美国Reg NMS法案（美国全国市场系统规则Regulation NMS）：引入新的竞争对手。最优价格最为唯一执行标准。买最便宜卖最贵。公平性和市场效率之间达到新的平衡。

【交易所竞争】衍生品合约不具有可互换性：CME的垄断性，CME买入CME卖出，不能在CBOT卖出。股票可以30多家交易，可互换性。理论上探讨，还未形成趋势。股票交易所竞争激烈。

【清算所竞争】清算可互操作性：任何产品清算可不同清算所清算。会被引入竞争。
